# Pooja Barot — Portfolio

Personal portfolio site for Pooja Barot, MBA (STEM) — Business Development Representative with 4+ years in net-new customer acquisition, consultative selling, and pipeline growth.

**Live site:** https://barotpooh.github.io/pooja-portfolio/

## Pages

- **Home** — overview, key results, site navigation
- **About** — background and career summary
- **Experience** — role-by-role timeline with measurable results
- **Projects** — selected work across acquisition, CRM, and account management
- **Skills** — core strengths and tools, with real usage examples
- **Education** — degrees and certifications
- **Contact** — ways to get in touch

## Built with

Plain HTML, CSS, and vanilla JavaScript — no build step or framework. Fonts via Google Fonts (Sora + Inter). Deployed with GitHub Pages.

Built in collaboration with [Claude](https://claude.com).

## Running locally

No build step required — open `index.html` directly in a browser, or serve the folder:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.
