# Pooja Barot — Portfolio

Personal portfolio site for Pooja Barot, MBA (STEM) — Business & Marketing Analyst specializing in GTM strategy, market strategy, and performance analytics.

**Live site:** https://barotpooh.github.io/pooja-portfolio/

## Pages

- **Home** — overview, key results, site navigation
- **About** — background and career summary, with photo
- **Experience** — role-by-role timeline with measurable results
- **Projects** — index of case studies, each with the full problem → process → outcome story
- **Skills** — core strengths and tools, with real usage examples
- **Education** — degrees and certifications
- **Contact** — ways to get in touch

## Case studies

Each project has its own page following a consistent structure (question → role → problem → process → outcome → takeaway): Hexafort GTM strategy, EuropeLab CRM pipeline, AB InBev × Echoes of Earth festival, ASU content operations, and personal AI automation.

## Built with

Plain HTML, CSS, and vanilla JavaScript — no build step or framework. Fonts via Google Fonts (Sora + Inter). Deployed with GitHub Pages.

Built in collaboration with [Claude](https://claude.com).

## Running locally

No build step required — open `index.html` directly in a browser, or serve the folder:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.
